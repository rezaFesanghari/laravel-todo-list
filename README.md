# ✅ TaskFlow

A modern and responsive **Task Management System** built with **Laravel 12**, designed to help users organize, prioritize, and manage their daily tasks efficiently.

> This project was developed as part of my Laravel portfolio to demonstrate clean architecture, authentication, CRUD operations, and modern UI development.

---

## ✨ Features

* 🔐 Authentication (Laravel Breeze)
* 👤 User Dashboard
* ✅ Create, Edit and Delete Tasks
* 📌 Task Status Management
* 🎯 Priority Levels
* 📅 Due Date Support
* 🔍 Search Tasks
* 🎨 Modern Responsive UI
* ⚡ Built with Livewire
* 💾 MySQL Database

---

## 🛠️ Tech Stack

* Laravel 12
* PHP 8.4+

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/taskflow.git
```

Go to the project directory

```bash
cd taskflow
```

Install dependencies

```bash
composer install
npm install
```

Copy environment file

```bash
cp .env.example .env
```

Generate application key

```bash
php artisan key:generate
```

Configure your database in the `.env` file.

Run migrations

```bash
php artisan migrate
```

Start the development server

```bash
php artisan serve
npm run dev
```
